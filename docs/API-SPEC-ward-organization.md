# 기관 연동 API 명세서 (보호자 앱)

> 보호자가 **기관번호**를 입력하면, 담당 사회복지사가 웹 대시보드에서 해당 피보호자를 조회할 수 있게 하는 기능.
> **상태: 🔜 PR #46 리뷰 중** — 머지 전이라 아직 서버에 반영되지 않았습니다. 계약(요청·응답 형식)은 확정이므로 목 데이터로 선구현 가능합니다.

---

## 0. 이 기능이 하는 일

- 보호자가 등록한 피보호자는 원래 **보호자만** 볼 수 있었습니다.
- 여기에 기관번호를 입력하면, 그 기관의 사회복지사도 **조회**할 수 있게 됩니다.
- **피보호자의 주인은 계속 보호자입니다.** 기관은 보기만 할 수 있고, 삭제하거나 건강정보를 수정할 수 없습니다.
- 연동은 언제든 해제할 수 있습니다.

> 기관번호는 **6자리 숫자**입니다. 기관 가입 시 서버가 자동으로 부여하며, 사회복지사가 웹에서 확인해 보호자에게 안내합니다.
> 앱에서 기관을 검색하거나 목록으로 고르는 기능은 없습니다. 보호자는 안내받은 번호를 그대로 입력합니다.

---

## 1. 공통 사항

**인증** — 보호자 로그인 토큰 필요 (`ROLE_USER`)
```
Authorization: Bearer <token>
```

**에러 응답 포맷** (기존과 동일)
```json
{ "status": 404, "code": "O003", "message": "존재하지 않는 기관번호입니다." }
```

---

## 2. 연동 상태 조회

```
GET /api/wards/me/organization
```

화면 진입 시 호출해서 어떤 UI를 보여줄지 결정합니다.

**연동 전 — 200**
```json
{
  "linked": false,
  "organizationId": null,
  "organizationName": null,
  "orgCode": null
}
```

**연동 후 — 200**
```json
{
  "linked": true,
  "organizationId": 3,
  "organizationName": "○○종합사회복지관",
  "orgCode": 1001
}
```

> ⚠️ 연동 전에도 필드 자체는 다 내려오고 **값만 `null`** 입니다. (필드가 아예 없는 게 아닙니다.)
> `organizationName`을 바로 참조하지 말고 **`linked`를 먼저 확인**해주세요.

---

## 3. 기관 연동

```
PATCH /api/wards/me/organization
```

```json
// 요청
{ "orgCode": 1001 }
```

```json
// 응답 200 — 연동된 기관 정보
{
  "linked": true,
  "organizationId": 3,
  "organizationName": "○○종합사회복지관",
  "orgCode": 1001
}
```

- 응답에 기관명이 담겨 오므로, **성공 후 재조회(GET) 없이** 바로 화면을 갱신할 수 있습니다.
- **이미 다른 기관과 연동된 상태에서 호출하면 새 기관으로 교체됩니다.** 에러가 아닙니다.
  기관을 바꿀 때 해제(DELETE)를 먼저 부를 필요가 없습니다.

---

## 4. 연동 해제

```
DELETE /api/wards/me/organization
```

```
응답 204 No Content
```

- 연동돼 있지 않은 상태에서 호출해도 **성공(204)** 합니다. (멱등)
- 해제 후에는 기관 대시보드에서 이 피보호자가 사라집니다.

---

## 5. 에러 처리

| 코드 | HTTP | 상황 | 프론트 처리 |
| --- | --- | --- | --- |
| `O003` | 404 | 존재하지 않는 기관번호 | 입력창 하단에 "존재하지 않는 기관번호입니다" 표시 |
| `M001` | 404 | 등록된 피보호자가 없음 | 피보호자 등록을 먼저 유도 |
| `C001` | 400 | `orgCode` 누락 | "기관번호를 입력해주세요" |
| - | 401 | 토큰 없음/만료 | 로그인 화면으로 이동 |

> `orgCode`는 **숫자(정수)** 입니다. 문자열로 보내지 말아주세요.
> 6자리 숫자이므로 입력창은 숫자 키패드 + 6자리 제한을 권장합니다.

## 6. 화면 흐름 예시

```
[기관 연동 화면 진입]
        │
        ├─ GET /api/wards/me/organization
        │
        ├─ linked: false ──▶ "기관번호 입력" 폼

        │
        └─ linked: true ───▶ "○○복지관과 연동됨"

                                 └─ [기관 변경] ──▶ PATCH (해제 불필요)
```

## 7. 참고 사항

- **기관번호는 기관 가입 시 자동 부여됩니다.** 6자리 숫자이며 기관마다 유일합니다.
  사회복지사는 웹에서 `GET /api/org/me` 의 `orgCode` 로 자기 기관번호를 확인합니다. (앱과는 무관)
- 연동 후 낙상이 발생하면 **보호자와 기관 양쪽 모두에게** 알림·푸시가 전송됩니다. 보호자 앱 쪽 알림 동작은 기존과 동일합니다.
- 피보호자 1명당 연동 가능한 기관은 **최대 1곳**입니다.
- 연동해도 피보호자의 **주인은 계속 보호자**입니다. 기관은 조회만 할 수 있고 삭제·건강정보 수정은 불가능합니다.
  보호자 앱에서 할 수 있는 일은 연동 전후로 달라지지 않습니다.
